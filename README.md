# FP16-multiplier-and-adder-MAC-
Bit-accurate IEEE-754 FP16 multiplier-accumulator (MAC) implemented in SystemVerilog. Features independent 3-stage multiplier and adder pipelines, hidden-bit handling, exponent alignment, sticky bits, leading-zero normalization, and round-to-nearest-even. Verified with a 13-element dot product against a Python FP16 golden model.
